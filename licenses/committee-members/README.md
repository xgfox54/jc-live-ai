# 위원 명단과 의원 사진 출처

- 출처: 제주특별자치도의회 공식 홈페이지의 상임위원회·특별위원회 소개
- 확인일: 2026-10-20
- 범위: 위원회 12개, 소속 항목 100개, 의원 사진 44개
- 보관: 홈페이지에 게시된 의원명·직책·선거구·의원 소개 주소와 사진 원본
- 무결성: `manifest.json`에 페이지·사진 주소와 SHA-256 기록
- 화면 표시: 위원회별 공식 출처, 의원별 소개 링크와 확인 날짜 제공
- 갱신: `node scripts/sync-committees.mjs` 실행 후 명단 변경 및 사진 확인 필요
- 사진의 권리와 이용 조건은 원 출처에 따름. 이 파일은 별도의 사진 이용 허락을 부여하는 문서가 아님

공식 페이지의 활동기간 오기나 의원 URL에 남아 있는 과거 대수 식별자로 현재 임기를 추정하지 않음. 수집 시점에 위원회 소개에 게시된 소속 명단을 사용함.
