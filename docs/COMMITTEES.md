## 동작

- 채널 선택 시 영상·전사문 왼쪽에 해당 위원회의 의원 명단 표시
- 의원 이름 선택 시 도의회 공식 의원 소개를 새 창으로 열기
- 좁은 화면에서는 영상 위에 명단 표시. 키보드와 마우스로 명단 접기·펼치기 가능
- 방송 주소 미등록 채널도 명단 열람 가능. 주소 대기 상태를 전사 진행 상태와 구분
- 자동 탐색은 공식 소관 정보 또는 위원회명이 확인된 제목에 따라 고정 채널 배정
- 위원회 불명·여러 위원회명 포함·다른 채널에 같은 영상 등록·해당 채널 수집 중인 경우 대기 사유 표시
- 기존 수집이 끝난 후 같은 위원회의 다음 방송으로 교체. 이전 방송·세션·회의록 보존
- 동시 전사 최대 8개. 9번째 입력 시작 거부 후 자동 감지는 재확인하며 수동 시작은 안내 표시

## 출처와 갱신

명단 원본: [상임위원회](https://www.council.jeju.kr/council/committees/committee.do), [특별위원회](https://www.council.jeju.kr/council/committees/special.do). 위원회별 주소는 `public/committees.mjs`에 보관. 페이지·사진 해시는 `licenses/committee-members/manifest.json`에 보관. 사진은 공식 홈페이지 원본을 로컬 정적 자산으로 제공.

```powershell
node scripts/sync-committees.mjs
npm test
npm run build:web
```

갱신은 관리자가 명시적으로 실행하는 작업. 명단 자동 갱신 기능 없음. 페이지 구조·인원 변경 시 검증 실패 여부와 실제 공식 페이지를 확인한 뒤 시험 기준 갱신 필요. 사진 이용 조건은 원 출처에 따름.

## 실행과 복구

```powershell
node src/main.mjs config.local.json --manual
node scripts/stop-live.mjs config.local.json
```

`--manual`은 자동 수집과 외부 게시를 시작하지 않는 로컬 확인 모드. 일반 실행은 기존 자동 감지 설정을 적용하므로 운영자 확인 후 사용. 첫 실행 시 기존 등록을 유지하고 비어 있는 채널만 추가.

중지 후 작업 전 소스 보관본과 SQLite 백업을 별도 폴더에 복원하여 실행. 현재 데이터베이스를 덮어쓰기 전에 이후 생성한 전사문·회의록·수정 이력을 별도 보관. StreamRecord 저장소·설치 데이터 변경 없음.
