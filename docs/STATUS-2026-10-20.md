# 2026-10-20 작업 정리

## 인계·실행 환경

Google Drive에 백업한 독립 JC-LIVE 프로젝트 복원. 기존 라이선스·출처 기록 보존. Node.js 24.18과 GTX 1660 Ti의 Vulkan 환경에서 실행 확인. 사용자 제공 StreamRecord_Icon_192x192.png를 프로젝트 아이콘에 적용.

기존 TEST_RESULTS.md는 최초 데스크톱 분리 시험의 기록. 이후 노트북 인계·화면 변경·자동 감지 시험과 구분해 보존.

## 저장소 포함 범위

GitLab 게시 시 발견한 Rust 의존성 보안 공지 RUSTSEC-2026-0190에 대응해 anyhow를 1.0.103으로 고정하고 Cargo 잠금 파일·라이선스 목록 갱신. 원래 실행 바이너리의 자산 목록 ASSETS.json은 기존 시험 출처로 보존. 변경한 의존성을 실행 바이너리에 적용하려면 워커 재빌드 필요.

수정 버전 근거: [RustSec 공지](https://rustsec.org/advisories/RUSTSEC-2026-0190.html).

Rust 빌드는 짧은 대상 경로와 UTF-8 C++ 옵션 적용. 기존 vendor/bindgen-0.69.5의 경고 6개는 유지. GPU 재빌드·갱신한 실행 바이너리의 실음성 시험은 이번 게시 검증에서 제외.

소스, 테스트, 아이콘, 설계 기준, 실행 안내, 설정 예시 및 라이선스 기록 포함. 운영 키·DB·원음·로그·개인 설정·모델·실행 바이너리 제외.
