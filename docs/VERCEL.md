# Vercel 공개 화면 운영

공식 명칭: JC-LIVE. 공개 주소: https://jc-live-ykh1.vercel.app/ . Vercel 프로젝트: `ykh1/jc-live`.

## 실행 위치

| 위치 | 담당 기능 |
|---|---|
| Windows PC | 공식 방송 탐색·자동 등록, 원음 저장, GPU 전사, 회의록 초안, 관리자 화면 |
| Vercel | 방송 선택·최대 2개 동시 시청, 공개 전사문·회의록 조회와 내려받기 |
| 비공개 Vercel Blob | 공개 화면에 제공할 전사문·회의록·방송 목록 보관 |

PC의 외부 포트 개방 없이 HTTPS로 자료 전송. 녹음·GPU 전사는 PC와 서버 실행 중에만 동작. Vercel 함수에서 장시간 녹음이나 GPU 워커 실행 불가.

관리자 페이지·관리자 키·원음·전사 DB·개인 설정은 배포 파일에서 제외. 별도 전송키로 공개 자료 전송 API 인증. 공개 조회 API는 읽기 전용. Blob 연결은 프로젝트 OIDC 사용.

## 배포 절차

1. 저장소 루트에서 `npm test`, `npm run build:web` 실행.
2. `web`에서 `npm ci` 실행. `web`만 Vercel 프로젝트에 연결.
3. `framework: null`, Node.js 24.x, 출력 `public`, 서울 함수 지역 `icn1` 적용.
4. 비공개 Blob 생성 후 해당 프로젝트 production 환경에 OIDC로 연결. `BLOB_STORE_ID` 자동 등록 확인.
5. 첫 배포 주소 확인 후 저장소 루트에서 `node scripts/configure-cloud.mjs https://배포주소.vercel.app config.local.json` 실행.
6. 새로 생성된 `data/cloud-sync.secret`의 전송키를 해당 Vercel 프로젝트 production 환경의 민감 변수 `JC_SYNC_SECRET`에 등록. 화면·로그·Git에 값 기록 금지.
7. production 재배포 후 로컬 서버 재시작. 관리자 자동 등록 메뉴의 공개 화면 전송 상태와 Vercel 조회 결과 확인.

`web/.vercelignore`로 로컬 환경 변수·의존성 폴더 제외. `scripts/build-web.mjs`는 공개 자산 13개만 복사하며 알 수 없는 출력 파일 발견 시 중단. 기존 서비스 폴더 전체 배포 금지.

## 전송 주기·오류

| 항목 | 기본값·동작 |
|---|---|
| 공개 방송 목록·최근 전사문 | 변경 시 60초 간격 전송 |
| 전체 회의록·이전 전사문 | 변경 시 300초 간격 전송. 처음 생성·상태 변경·100개 초과 새 구간은 우선 전송 |
| 이용자 브라우저 조회 | 30초 간격. 화면에 마지막 서버 전송 시각 표시 |
| 유휴 상태 | 변경 없는 자료 재전송 생략. 성공 이력은 로컬 DB에 보관 |
| 서버 종료 | 남은 회의록 생성 후 최종 전송 시도 |
| 전송 실패 | 관리자 화면에 오류 안내 후 다음 주기 재시도. 로컬 수집·전사 지속 |
| 본문 크기 | 100 KB 초과 시 gzip 압축. 전송 본문 최대 3.5 MB, 압축 해제 후 최대 64 MB. Blob도 압축 보관. 긴 조회·내려받기는 gzip 지원 |

공개 화면에는 전송 간격·네트워크·전사 대기 시간만큼 지연 발생. 방송 영상과 전사문 시각의 정밀 동기화는 미검증. 인터넷 단절 중에는 마지막 성공 자료만 공개 조회 가능.

## 요금·한도

2026-10-20 확인 기준 Hobby Blob 무료 범위: 저장 1 GB, 전송 10 GB, 읽기 등 단순 작업 10,000회, 쓰기 등 고급 작업 2,000회/월. 한도 도달 시 서비스 제한 가능. 매분 변경 자료를 쓰거나 이용자가 반복 조회하면 한도를 빠르게 소진할 수 있음. 사용량은 Vercel Usage와 Storage에서 확인. 유료 요금제 전환·추가 구매는 운영자 결정 사항.

근거: [Blob 사용량·요금](https://vercel.com/docs/vercel-blob/usage-and-pricing), [함수 제한](https://vercel.com/docs/functions/limitations).
