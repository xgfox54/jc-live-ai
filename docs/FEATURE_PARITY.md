## 실행·중지·복구

```powershell
Set-Location '<JC-LIVE 저장소 경로>'
node src/main.mjs config.local.json --manual
```

`--manual`은 복원본 검토용 실행 옵션임. 자동 탐색·자동 수집·자동 AI·공개 전송을 시작하지 않으며 운영 설정 파일 보존. 수동 입력·시험·관리자 요청은 사용 가능함. 관리자 주소는 `http://127.0.0.1:4320/admin`. 관리자 키는 복원한 `data/access.secret` 사용.

정상 운영 전에는 랩탑 서버 종료 여부와 공개 전송 담당 PC 확인 필요. 일반 실행 명령은 `npm start`. 후보정·AI 회의록은 저장한 연결 사용. 이번 검증에서 외부 AI 호출 없음. DB 추가 테이블은 `review_state`, `audio_jobs`이며 기존 전사와 원음 보존. 편집 본문을 비워 저장하면 자동 본문 사용. 재전사 결과는 별도 기록에서 확인.

```powershell
node scripts/stop-live.mjs config.local.json
```

중지 후 `data/` 전체와 `config.local.json` 보관. 원본은 상위 폴더의 `private-state.zip`, `JC-LIVE.bundle`에 보존. 롤백은 원본 묶음을 새 폴더에 복원하는 방식. 기존 데이터 삭제·덮어쓰기 없음.

## 시험 범위

자동시험 86개 통과. 실제 저장 원음의 GPU 재전사·CPU 참여자 분석·파일 업로드 전사·WAV API 확인. Chrome 1440px·820px·390px에서 검색·원문 비교·회의록 생성·인용 이동·편집·확대·로그아웃 확인. AI 응답은 합성 자료 사용.

8개 승인 음원 60초 실시간 속도 입력과 공개 SSE 연결 300개 통합시험 통과. 2시간·10시간 시험, AI 동시 부하, 실제 방송 시작 감지, 사람 검수 대비 인식·참여자 정확도, 영상 30초 정밀 동기화는 이번 변경본에서 미실시. 공개 사이트 반영 미실시.

Ollama API는 [공식 문서](https://github.com/ollama/ollama/blob/main/docs/api.md) 확인. 모델 다운로드·삭제는 모의 응답 시험이며 실제 다운로드·삭제 미실시. 실제 마이크 장치 권한 시험 미실시.

참여자 엔진·모델 출처와 해시는 `licenses/diarization/runtime-manifest.json`, `ASSETS.json`에 보관. CPU AVX2 필요. 임시 번호는 실제 이름이나 검증된 신원 정보가 아님.
