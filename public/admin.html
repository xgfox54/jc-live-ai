영상 등록·수집

방송을 선택하면 등록 내용을 편집할 수 있습니다.

방송 정보

YouTube 방송 주소와 의회 방송 상세 주소를 30초 간격으로 확인합니다. PC와 서버가 켜져 있어야 합니다. 탭 공유 방식은 수동으로 시작합니다.

수집 중인 방송은 중지 후 편집합니다. 저장하면 이용자 화면의 방송 목록에 반영됩니다.

음원 수집

주소 방식은 서버에서 수집합니다. 탭 공유 방식은 해당 영상을 재생한 뒤 탭 오디오를 공유합니다.

입력 장치는 브라우저 권한을 허용한 뒤 표시합니다. 스테레오 믹스가 Windows 입력 장치로 제공될 때 선택할 수 있습니다. 장치 이름은 서버에 저장하지 않습니다.

방송을 등록하면 자동 감지 상태를 표시합니다.

자동 수집은 원음 저장을 포함합니다. 수집 중지를 누르면 자동 감지도 꺼집니다. 저장 한도에 도달하면 자동 감지를 끕니다.

음원 수집은 이용자의 영상 재생과 별도로 동작합니다.

녹음 파일 첨부·전사

최대 256MiB. 해당 슬롯이 수집 중이면 파일 전사를 시작하지 않습니다.

공식 채널의 새 생방송을 등록합니다

공식 YouTube 채널과 의회 홈페이지를 30초 간격으로 확인합니다. 같은 방송은 한 번만 등록합니다.

회의록 열기

탐색을 꺼도 등록된 방송의 자동 감지·수집은 계속됩니다. 방송별 중지는 영상 등록·수집 메뉴에서 수행합니다.

PC와 서버가 켜져 있어야 합니다. 방송 시작 부분부터 수집을 요청하지만 제공자의 보관 범위에 따라 일부가 누락될 수 있습니다. 회의록에서 수집 범위와 누락 기록을 확인합니다.

위원회별 12개 채널을 고정 운영합니다. 동시 전사는 최대 8개이며, 같은 위원회의 다음 방송은 기존 수집 종료 후 배정합니다. 위원회를 확인하지 못한 방송은 등록 대기 상태로 남깁니다. 회의록은 방송별로 보존합니다.

발견한 방송

세부 설정

모든 방송의 수집과 남은 음성 처리를 마친 뒤 저장합니다. 저장한 값은 다음 실행에도 유지됩니다.

추가 추론이 발생합니다. 입력 수와 GPU 처리량을 측정한 뒤 사용합니다. 미확정 문장은 회의록·최종 전사에 넣지 않습니다.

기존에 저장한 원음은 이 설정으로 삭제되지 않습니다.

현재 전사 엔진

모델·처리 장치·탐색 수 변경은 서버 설정 파일 수정 후 재시작이 필요합니다.

회의록 받아쓰기 검토·수정

문장을 선택해 수정합니다. 원문과 수정 이력은 별도로 보존합니다.

AI 후보정·분야별 단어장

원문을 보존하고 후보를 생성합니다. 적용한 문장은 회의록 받아쓰기와 회의록에 반영됩니다.

후보정 AI 연결

OpenAI 호환 API 기본 주소를 입력합니다. 프록시 인증키가 없는 로컬 연결은 비워 둡니다. 주소를 바꾸면 기존 키를 지웁니다.

로컬 AI는 녹음·전사 종료 후, 프록시는 수집 중에도 순차 생성합니다. 회의록 받아쓰기와 참고어를 선택한 서버에 전송합니다. 숫자·길이 경고가 있는 후보는 공개하지 않고 이 화면의 검토 목록에 남깁니다. 실패한 작업은 1분부터 최대 30분 간격으로 다시 시도합니다. 직접 중단한 작업은 다시 시작할 때까지 멈춥니다.

방송별 단어장

회의 분야

쉼표나 줄바꿈으로 구분합니다. 직접 입력한 말과 선택 분야의 대표어부터 최대 3,000자를 사용합니다. 음성 인식 참고어와 별도로 후보정에만 사용합니다.

후보정에 전달할 참고어

후보 생성·검토

방송 기록을 선택해 주세요.

숫자나 문장 길이가 크게 바뀌면 경고합니다. 경고가 없어도 인명·부정 표현·발언 취지를 원음과 대조해야 합니다.

일괄 적용은 선택한 방송 전체의 경고 없는 미검토 후보에 적용합니다. 직접 수정한 문장은 덮어쓰지 않습니다.

방송 기록과 AI 회의록

원문을 보존하고 저장된 기록 전체를 검토합니다. AI 작성 내용은 근거 인용과 함께 확인합니다.

원음 듣기는 저장 파일과 시간축을 확인할 수 있는 구간만 제공합니다. 참여자 번호는 실제 이름을 의미하지 않습니다.

AI 구조화 회의록

AI 후보정에 저장한 연결·모델을 사용합니다. 요약·결정·제안·조치·수치·미결 사항을 근거 인용과 대조합니다. 완료한 묶음은 중단 후 재사용합니다.

생성 대기

1분마다 새 발언을 확인합니다. 로컬 AI는 수집 종료 후 처리합니다. 프록시를 선택하면 해당 서버로 회의록 받아쓰기를 전송합니다.

시각별 누적 요약

참여자 이름 지정

자동 분석한 참여자 번호에 실제 발언자 이름을 지정합니다. 지정한 이름은 회의록의 발언 내용 정리와 받아쓰기 표시에 사용합니다. 원음으로 확인한 뒤 지정해 주세요.

회의록 본문 직접 수정

직접 수정한 본문은 자동 생성으로 덮어쓰지 않습니다. 비우고 저장하면 최신 자동 생성 본문을 사용합니다. 이전 버전은 서버에 보존합니다.

저장 원음 재전사·복구

모든 수집 종료 후 공유 전사 워커로 처리합니다. 기존 전사는 보존하며 결과는 별도 재전사 기록으로 엽니다. 중간 누락이 있으면 전체 원음 재전사를 이용합니다.

AI 연결 보관

AI 후보정 메뉴에서 저장한 현재 연결을 이름별로 보관합니다. 인증키는 암호화하며 목록에 표시하지 않습니다. 연결을 전환하면 자동 생성·적용은 꺼집니다.
